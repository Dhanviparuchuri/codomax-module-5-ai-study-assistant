# AI Study Assistant 📚

## About
AI Study Assistant is a simple app that helps students create personalized study prompts. Students enter a subject, topic, available study time, and current level. The app generates a prompt that can be used with ChatGPT or Gemini to produce a study plan.

## Features
- Collects subject and topic
- Lets students choose study time and skill level
- Creates a personalized study prompt
- Suggests explanations, a schedule, practice questions, and revision points

## Tools Used
- Python
- Streamlit
- ChatGPT or Gemini for generating the study plan from the prompt

## How to Run
1. Install the required package:
   `pip install -r requirements.txt`
2. Run the app:
   `streamlit run app.py`

## Note
This app creates the prompt. An AI assistant such as ChatGPT or Gemini generates the study plan when the prompt is pasted into it.
